# Rediseño visual — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplicar el rediseño "concreto y señalización" aprobado en maqueta a toda la app, con gráficas e indicadores nuevos, vista de oficial mobile-first y PDF profesional.

**Architecture:** Tokens en `tailwind.config.js` + primitivas en `web/src/components/ui.tsx` y gráficas HTML en `web/src/components/graficas.tsx`; un endpoint nuevo `GET /reportes/indicadores` cuyo cálculo vive en la función pura `server/src/lib/indicadores.ts`; el PDF se reestructura en `server/src/lib/avancesPdf.ts` con helpers puros probados.

**Tech Stack:** TypeScript, React 18, React Query v5, Tailwind, Express 4, Prisma 5 (SQLite), pdfkit.

**Spec:** `docs/superpowers/specs/2026-10-22-rediseno-design.md`

## Global Constraints

- Rama `rediseno` desde `mejoras-ux`; un commit por tarea con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Sin dependencias nuevas. Fuentes IBM Plex Sans/Mono por `<link>` de Google Fonts en `web/index.html`.
- Colores exactos del spec, Meta 1. Espaciado: `space-y-6` entre secciones, `gap-4` entre tarjetas, filas de lista con `divide-y`.
- Pruebas de lógica: `node:test`, `*.test.ts` junto al módulo, `server/node_modules/.bin/tsx --test <archivo>` con `TZ=America/Mexico_City`.
- Compilación por tarea: `cd server && npx tsc --noEmit -p .` y `cd web && npx tsc -b` sin errores.
- UI: `ux-check.cjs` (scratchpad) — cada tarea de UI agrega aserciones; todas las existentes siguen pasando (se ajustan textos/selectores solo si el diseño los cambió, con ruling).
- Roles sin acceso financiero nunca reciben montos (server) ni los ven (web).

## Review Focus

1. **Celular 390 px:** ninguna ruta de ningún rol con `scrollWidth > clientWidth` → check `movil` (Task 2) recorre todas las rutas.
2. **Gerente/Supervisor en Dashboard e Indicadores:** sin "Gasto diario", sin costos de días-hombre ni montos → test de `calcularIndicadores` con `verFinanciero=false` (Task 3) y aserción con `lucia@piloto.test` (Task 5, Task 8).
3. **Periodo sin datos / obra sin partidas / presupuesto 0:** gráficas con estado vacío, sin `NaN%` ni barras > 100% de ancho → tests en Task 3 y aserción en Task 5.
4. **Supervisor solo ve sus obras en Indicadores** (mismo fallo que personas en `mejoras-ux`) → test de alcance en Task 3 vía `obraIds`.
5. **PDF con nombres largos, sin logo, con adjunto PDF y 0 avances:** no se encima texto ni sale página en blanco → render con PyMuPDF en Task 10.
